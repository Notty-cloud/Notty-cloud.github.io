Projects

Deployed — AWS dev environment

Hurricane Preparedness Portal — Barbados

A serverless portal for hurricane alerts, emergency shelter lookup, and outage reporting, built end-to-end on AWS and deployed with CDK across five stacks. Every route has been exercised against real AWS — not just mocked — including forcing a live IAM denial to confirm the API fails loudly (a 500) rather than silently returning an empty result on a life-safety endpoint. Shelter data carries its official source and year on every record, and personal data is deliberately minimal: outage reports carry no reporter identity, and subscriber emails are never stored, only passed through to SNS.

AWS Lambda API Gateway DynamoDB Cognito SNS CloudFront AWS CDK Python

Deployed — Grocery pilot, Barbados

Caribbean Data Tracker (CSDT)

An AI-enabled SaaS platform built to remove the need for in-house analysts at Caribbean businesses — demand forecasting, inventory planning, and industry-specific factor analysis (weather, holidays, seasonality) translated into plain-language recommendations. Launching with a grocery retail pilot in Barbados, with restaurant, pharmacy, retail, and government verticals already implemented behind a configuration-over-code design rather than hardcoded per-industry logic. The Flask service owns auth, multi-tenancy, and all forecasting logic; the Node.js layer is a deliberately thin gateway in front of it. Built with secure multi-tenant data isolation, role-based access control, and audit logging, and designed with ISO/IEC 42001 AI-governance principles — risk management, transparency, and data privacy — in mind from the start. Backed by 485 passing tests in CI.

React + TypeScript Node.js / Express Python / Flask PostgreSQL Docker Compose JWT Auth
